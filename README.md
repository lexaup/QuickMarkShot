# 轻截

一个原生、轻量的 macOS 截图与快速标注工具，无第三方依赖。

## 功能

- 菜单栏常驻，不占用 Dock
- `⌘⇧2` 截取区域或窗口
- `⌘⇧1` 截取主屏幕
- 截图后立即标注：矩形、圆形、箭头、自由画笔
- 自定义颜色和线条粗细
- `Shift` 拖动绘制正方形或正圆
- 撤销、重做、清除、复制到剪贴板、保存 PNG
- 也可从菜单栏打开已有图片进行标注

## 标注快捷键

| 操作 | 快捷键 |
| --- | --- |
| 矩形 | `R` |
| 圆形 | `O` |
| 箭头 | `A` |
| 画笔 | `P` |
| 撤销 | `⌘Z` |
| 重做 | `⇧⌘Z` |
| 复制 | `⌘C` |
| 保存 | `⌘S` |
| 关闭窗口 | `Esc` |

## 构建与安装

```bash
./build.sh
./install.sh
```

应用会安装到 `~/Applications/轻截.app`。首次截图时，macOS 会要求授予“屏幕与系统录音”权限；授权后重新打开轻截即可。
