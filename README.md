# 轻截

一个原生、轻量的 macOS 截图、录屏与快速标注工具，无第三方运行时依赖。

## 功能

- 菜单栏常驻，不占用 Dock
- `⌘⇧2` 截取区域或窗口
- `⌘⇧1` 截取主屏幕
- 截图后立即标注：矩形、圆形、箭头、自由画笔
- 自定义颜色和线条粗细
- `Shift` 拖动绘制正方形或正圆
- 撤销、重做、清除、复制到剪贴板、保存 PNG
- 也可从菜单栏打开已有图片进行标注
- `⌘⇧5` 打开录屏选择器
- 录制整个显示器、局部区域、指定窗口或指定应用
- 可选系统声音、鼠标指针与点击提示
- 鼠标跟随放大支持 `1.5×`、`1.8×`、`2.0×`，使用弹簧缓动平滑追踪
- MP4（H.264 + AAC）自动保存到 `~/Movies/轻截录屏`
- 原生菜单栏界面与 macOS 27 Liquid Glass 风格多尺寸应用图标

## 标注快捷键

| 操作 | 快捷键 |
| --- | --- |
| 矩形 | `R` |
| 圆形 | `O` |
| 箭头 | `A` |
| 画笔 | `P` |
| 撤销 | `⌘Z` |
| 重做 | `⇧⌘Z` |
| 复制 | `⌘C` |
| 保存 | `⌘S` |
| 关闭窗口 | `Esc` |

## 录屏

从菜单栏选择“开始录屏…”，或者按 `⌘⇧5`。选择录制来源和选项后开始；右上角的悬浮控制条可停止录制。启用“鼠标跟随放大”时，轻截会在停止后短暂处理画面并保留系统音轨，完成后自动在 Finder 中定位成片。

## 构建与安装

```bash
./build.sh
./install.sh
```

应用会安装到 `~/Applications/轻截.app`。需要 macOS 15 或更高版本。首次截图或录屏时，macOS 会要求授予“屏幕与系统录音”权限；授权后重新打开轻截即可。
