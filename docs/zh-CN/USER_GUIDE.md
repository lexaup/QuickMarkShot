# 轻截中文使用手册

## 1. 安装、权限与菜单栏

将 `轻截.app` 放入“应用程序”后打开。首次截图或录屏时允许“屏幕与系统录音”，随后完全退出并重启轻截。应用只在状态栏显示；`⌘⇧0` 可隐藏或恢复状态栏入口，该选择会保存。

## 2. 截图

- `⌘⇧1`：截取主屏幕。
- `⌘⇧2`：拖动选择区域；点击窗口可捕获窗口。
- 也可从状态栏菜单打开已有图片。

截图完成后会直接打开标注窗口，保留捕获的源像素尺寸。

## 3. 标注

选择矩形、圆形、箭头或画笔后拖动绘制；设置颜色和线宽。绘制矩形/圆形时按住 Shift 可约束为正方形/正圆。工具栏可撤销、重做、清除、复制到剪贴板或保存 PNG，Esc 关闭窗口。

## 4. 录屏

按 `⌘⇧5` 或从菜单选择“开始录屏”，选择：

- 整个显示器
- 自定义区域
- 指定窗口
- 指定应用

可按需开启系统声音、鼠标指针、点击提示和鼠标跟随放大。应用来源列表会显示应用图标。开始后使用右上角悬浮控制条停止。

## 5. 鼠标跟随放大

可选 1.5×、1.8× 或 2.0×。停止录制后轻截会在本机处理画面并尽量保留系统音轨；若放大后处理失败，会保留原始录屏并显示原因。

## 6. 保存位置

录屏使用 MP4（H.264 + AAC），默认保存到 `~/Movies/轻截录屏`，完成后在 Finder 中定位文件。截图由保存面板选择 PNG 位置。

## 7. 更新与卸载

更新前退出轻截，用新版 App 替换旧版。卸载时退出并删除 App；用户已保存的截图和录屏不会自动删除。
