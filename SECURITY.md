# Security Policy

请通过 GitHub 仓库的 **Security → Advisories → Report a vulnerability** 私下提交安全问题，不要在公开 Issue 中附上漏洞细节或私人捕获内容。说明受影响版本、权限前提、复现步骤和影响。

Report vulnerabilities privately through **Security → Advisories → Report a vulnerability**. Do not place exploit details or private captured content in public issues. Include affected versions, permission prerequisites, reproduction steps, and impact.
